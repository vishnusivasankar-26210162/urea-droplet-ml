# Urea Droplet ML

Estimate added urea concentration from milk-droplet images.

## Project question

Can droplet colour, approximately two minutes after adding
p-DMAB, estimate added urea concentration?

## Target

Added urea concentration in % w/v, over the range 0–2.0%.

## Repository structure

- `data/raw/`: Original data (not committed).
- `data/interim/`: Cut-out images (not committed).
- `data/processed/`: Metadata and extracted features.
- `splits/`: Train/test assignments.
- `src/`: Reusable Python scripts.
- `notebooks/`: Exploration and analysis.
- `tests/`: Unit tests.
- `reports/`: Evaluation and decision records.
- `results/`: Metrics and figures.
- `docs/`: GitHub Pages website.
